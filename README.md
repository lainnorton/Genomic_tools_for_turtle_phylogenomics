# Genomic_tools_for_turtle_phylogenomics

## Introduction

This repository contains a collection of Perl scripts for population and evolutionary genetics analyses. The scripts are organized into three main directories: `PSMC`, `Sequence_variations`, and `evolutionary_analysis`. Below is a description of the scripts and their functionalities.

---

## PSMC

* **`psmc_normalized.pl`**

    This script normalizes PSMC results across different species. This allows for a direct and standardized comparison of inferred demographic histories between species.

---

## Sequence_variations

* **`01_print_gene_seq_mutition_table.pl`**

    This script takes alignments of single-copy orthologous proteins as input and extracts the sites that show variations among the aligned sequences.

* **`02_get_mutation_type.pl`**

    This script filters the variation sites identified by the previous script based on a user-specified list of species. This is useful for focusing on mutations relevant to a particular lineage or set of species.

---

## evolutionary_analysis


### 1. MAF to VCF Conversion

These two scripts work in tandem to convert MAF (Multiple Alignment Format) files into VCF (Variant Call Format) files.

* **`convertMaf2List.pl`** (Step 1)
    
    This is the first step in the conversion process, transforming a MAF file into an intermediate list format.

* **`convertlist2vcf.pl`** (Step 2)
    
    This script takes the list file generated by `convertMaf2List.pl` and completes the conversion to a VCF file.

### 2. Gene Tree Construction

* **`connect.pep.pl`**

    This script concatenates single-copy orthologous genes from multiple species. The resulting concatenated sequence alignment can be used to construct a robust gene tree.

### 3. Species Tree Construction from Synteny Blocks

* **`random_cut_synteny.pl`**

    This script is designed to work with FASTA files that have been converted from whole-genome or synteny alignments in MAF format. It randomly fragments the alignment into smaller blocks, which can then be used as individual markers for constructing a species tree.
